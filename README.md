# notifycli

Unified notification system CLI for testing and sending notifications through external messaging providers (Slack, Discord, webhooks)

## Installation

```bash
npm install -g notifycli
```

## Usage

```bash
npx notifycli <input>
```

Or install globally:

```bash
npm install -g notifycli
notifycli <input>
```

## Development

```bash
bun install
bun run build
bun run test
```
